# Product Context: Meadowist

## Product Status
Meadowist is a small website that hosts projects related to **environmental restoration, local parks, planting, and stewardship**. The home page is built and live-ready at `meadowist.dev`.

**Mission statement:** *Resources for maintaining Seattle's urban forests and parklands.*

## Why This Project Exists
Meadowist serves as a hub/portfolio for small tools and resources that help people maintain and steward Seattle's urban forests and parklands. Each project is hosted on a subdomain (e.g., `gsp-events.meadowist.dev`), and the home page links them together.

## How It Should Work
- The home page (`meadowist.dev`) displays the meadowist logo and mission statement
- A "Projects" section lists each sub-project as a card with its logo, name, description, and link
- Each project card links out to its own subdomain in a new tab
- The current layout is a simple card grid, so new projects can be added easily

## User Experience Goals
- Clean, simple design with subtle green accents
- Clear mission statement at top of the page

## Key Projects
- **Work Party Notifier** (`gsp-events.meadowist.dev`) — monitors the Green City Partnerships calendar and emails subscribers about new volunteer events
